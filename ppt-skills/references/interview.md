# 需求访谈、风格选择、大纲与样张确认

全程用中文。顺序：访谈 → 风格选择 → 大纲确认 → 样张确认。每一步都等用户回答后再往下走，不把推荐项当成用户已同意。

## 1. 访谈方法（内置 grilling）

把需求当成一棵决策树，分轮提问：

- 每轮问「前置条件已经定了、现在就能回答」的全部问题；依赖未定答案的问题留到下一轮。
- 每题给 2–3 个具体选项，推荐项放第一个、标签末尾加「(推荐)」，在描述里说明理由或取舍；其它选项也写清楚。开放问题也给候选答案。
- 用提问工具 `request_user_input` 提问，按工具实际限制（目前约每次 1–3 题、每题 2–3 个选项），系统会自动加「其他」供用户自由填写。一轮问题多就连续调用几次，重要的放前面。工具不可用时，在对话里列编号问题，每题附推荐答案。
- 能自己查到的事实（用户给的文件、材料里写了什么）自己查，不问用户；用户已经说清楚的不再问。
- 每轮回答后重新算下一轮要问的问题，直到没有未定的决策。

## 2. 要问清的决策（按缺口挑着问）

| 决策 | 问什么 |
|---|---|
| 用途与受众 | 什么场合（汇报/答辩/路演/培训/宣讲…）、谁看、希望观众记住或做什么 |
| 内容材料 | 材料在哪；哪些数据、原文、专有名词必须原样保留 |
| 页数与结构 | 页数或演讲时长；章节；要不要封面、目录、章节页、结尾页 |
| 画幅与语言 | 16:9（推荐）/ 4:3 / 3:2；幻灯片文字用什么语言 |
| 品牌要求 | 指定配色、字体、logo；要不要页码/页脚（默认都不加） |
| 信息密度 | 高密度（推荐默认：内容页尽量 4 个以上模块、20 个以上信息点）/ 适中 / 简洁留白 |

固定规则，不用问：**只用用户提供的材料，不补充新事实、不编数据**。某页材料不够撑满时，对已有内容做结构化拆解（如把一件事拆成背景/动作/结果），或用大字号、中心聚焦的版式，而不是编内容。框架图切分只在用户主动提出时启用，不主动问。

访谈结束后把结论写进 `RUN/brief.md`（用途、受众、页数与结构、画幅、语言、品牌要求、信息密度、必须保留的内容）。

## 3. 风格选择

根据主题、受众和场合**现编 4 个风格选项**，不要每次都给同一套。每个选项写：

- 风格名 + 一句话气质；
- 配色：主色 / 辅色 / 强调色 / 背景（写 hex）；
- 典型版式和视觉元素；
- 为什么适合这个主题。

先看 [styles.md](styles.md)：和主题匹配的参考风格可以编成其中一个选项，并注明「参考图：目录名」。

提问工具一题放不下 4 个选项，所以**用编号列表在对话里展示**，请用户回复编号（可多选），也可以说自己的想法或改某个选项。

## 4. 大纲确认

按确认的结构写 `RUN/outline.md`，每页包含：

- 页码、页面角色（封面/目录/章节页/内容页/结尾页）；
- 标题：叙事化（「用量半年翻倍」而不是「关键数据」），避免「探索、旅程、赋能、总而言之」这类空话；
- 核心信息：一句话说清这页要让观众记住什么；
- 版式框架：从 [image-prompts.md](image-prompts.md) 的版式目录里按内容结构挑，**每页不重复**；
- 【页面文字】：这一页上要出现的**全部文字**，逐字写出（标题、导语、各模块标题/要点/数字、底部结论）。高密度风格的内容页按 image-prompts.md 的「内容优先」把内容写厚，但只用用户材料。

在对话里按页给出精简版（标题 + 核心信息 + 版式 + 主要文字），并给出 outline.md 的路径，请用户确认或修改。改完再确认一次，确认后的文字就是之后出图和转换时的唯一文字依据。

## 5. 样张确认

- 从大纲里挑一张最能体现版式和信息密度的**内容页**，用户选的每个风格各出 1 张样张（同一页、不同风格，方便比较）。出图方法见 [image-prompts.md](image-prompts.md)，存到 `RUN/samples/<风格名>.png`。
- 把样张展示给用户，请用户选定一个风格，或提修改意见（配色、密度、版式气质）。按意见改提示词重出，直到用户满意。
- 定稿后把最终风格写进 `brief.md`：风格名、配色 hex、字体方向、版式气质、参考图（若有）、提示词里的【整体风格】原文。选中的那张样张直接作为该页的正式图，不重复生成。
