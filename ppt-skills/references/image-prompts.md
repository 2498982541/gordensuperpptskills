# 幻灯片出图

每页是一张由图像模型直接生成的完整幻灯片图（含全部真实文字），之后再交给子代理还原成可编辑页。

## 1. 出图规则

- **工具与质量**：用 Codex 内置 `image_gen`，不指定模型（平台自动用当前最新模型）。工具若提供质量参数就设为最高档；没有就在提示词里写「最高质量、高分辨率、文字清晰锐利」。
- **一页一次调用**：每页单独调用；不满意只重出那一页。
- **只用模型出图**：不能用 Python/SVG/HTML/PPT 形状画页面，也不能在生成图上用代码补字、盖字。
- **保存**：生成图默认在 `$CODEX_HOME/generated_images/...`，**复制**到 `RUN/pages/NN/source.png`（保留原图），同一页的提示词存到 `RUN/pages/NN/prompt.md`。
- **参考图**：选定风格有参考图时，每页挑 1–2 张版式最接近的作为风格参考传入（工具有本地图片参数就用参数；否则先用 `view_image` 打开再调用），提示词写明「参考图只用于配色和版式气质，不要照搬其中的文字、数据和品牌」。
- **全篇统一**：同一段【整体风格】原样放进每页提示词；配色写死 hex，不逐页换色。
- **检查每页**：漏模块、版面杂乱、风格跑偏、出现占位符或空白模板 → 改提示词重出。个别错字不必重出：转换时文字层会用 outline 里确认过的原文。
- **少用纯绿**：非必要不要大面积使用接近 #00FF00 的纯绿（转换时用绿幕抠图）；风格本身是绿色系也没关系，转换时会换抠图底色。

## 2. 内容优先（复杂排版的前提）

「排版太简单」几乎都是因为每页内容太薄。高密度风格下，内容页的内容量基线：

- 1 句导语，含 2–3 个强调色高亮的关键词；
- 3–4 个并列模块；每个模块 = 模块标题 + 2–3 条要点 + 1 个特大号指标数字（带单位或说明）+ 1 个标签/进度条/百分比；
- 1 条底部总结横幅；
- 合计约 20 个以上文字信息点。

内容不够时先把用户材料做结构化拆解（例如把「上市」拆成时间/募资额/意义），**不编数据、不补新事实**；实在不够就用大字号、中心聚焦的版式。

## 3. 复杂度清单（高密度风格的内容页至少占 4 项）

1. 小节标题区：编号（01 / 1.1）+ 标题 + 标题下短强调线；
2. 一句导语，关键词用强调色高亮；
3. 中心高阶图表，或 3–5 列模块卡片；
4. 模块内分层：子标签横幅 + 带小图标的要点 + 特大号重点数字；
5. 微件：标签胶囊、进度条（带 %）、连接线与箭头、节点编号；
6. 底部通栏总结横幅。

**豪华 ≠ 浮夸**：清晰永远第一。过度辉光、戏剧化 3D 光效、浓重金属/玻璃质感会让画面花哨难读。复杂度来自框架结构和信息量，不来自光效堆叠；强调色只点睛（数字、关键词、横幅），其余用主色和中性色。「满而不乱」：严格网格、对齐、留白和层级。

可直接组合的高密度组件：KPI 芯片带（4–5 枚小卡，每枚大数字 + 小字说明）、里程碑缎带（底部时间轴，节点写年份 + 事件）、带坐标轴和数据标签的迷你折线/柱状图、分层架构带（3–5 条水平层，每层若干模块卡）、侧栏 KPI 栏、地图 + 定位连线、阶段大卡时间轴、底部主张横幅。也可以加一层与主题相关的极淡背景底纹（如路网、城市天际线、电路线），增加质感但不抢文字。

## 4. 版式目录（按内容结构选，同一套 PPT 每页不重复）

| 内容结构 | 推荐版式 |
|---|---|
| 顶层战略 / 支撑体系 | 房子型架构（屋顶 = 愿景，立柱 = 支柱，地基 = 底座） |
| 生态闭环 / 价值循环 | 莫比乌斯环、无限循环符号 |
| N 步循环 | N 节点闭环、五边形/六边形闭环，中心放核心图标 |
| 多要素并列总览 | Bento 便当盒看板（大小不一的网格单元） |
| 多维能力 / 评估 | 同心圆雷达 |
| 分层体系 / 技术栈 | 多层 3D 架构（3–5 层，层间有数据流） |
| 协同 / 双轮驱动 | 双圆交织、两环咬合 |
| 多引擎发力 | 三环重叠、多重同心圆 |
| 单一指标 / 完成度 | 半圆仪表盘、环形进度 |
| 问题诊断 / 归因 | 鱼骨图 |
| 筛选 / 转化 | 漏斗 |
| 现状评估 | SWOT 矩阵、四象限 |
| 线性增长 / 阶段递进 | 3D 折叠彩带箭头、3D 阶梯 |
| 时间线 / 路线图 | 锯齿时间轴、蜿蜒里程碑路径 |
| KPI 总览 | 全景 Dashboard（多卡片 + 迷你图） |
| 层级 / 优先级 | 金字塔、堆叠层 |
| 中心辐射 / 概念图 | Hub-Spoke 放射 |

按用户内容自身的结构选（「8 大策略循环」→ 8 节点闭环），也可以用目录外的复杂信息图。不要在图上写出版式名称。

## 5. 每页提示词模板

每页一份自包含的提示词（颜色、版式、全部文字都写死，可以单独重出），存为 `pages/NN/prompt.md`：

```text
生成一张 <16:9> 横版演示幻灯片图片，最高质量、高分辨率，文字清晰锐利。四周留适度页边距，关键内容不要贴边。

【整体风格】<brief.md 里定稿的整体风格原文：风格名、背景、主色/辅色/强调色 hex、卡片与图标风格、字体方向>
【本页角色】<封面 / 目录 / 章节页 / 内容页 / 结尾页>
【核心信息】<这一页要让人记住的一句话>
【版式结构】<逐区域写死：顶部（编号 + 标题 + 短分割线 + 导语）；主体（<版式框架>，N 个模块，各模块内部分层）；侧栏/角落；底部横幅>
【图表形式】<本页的版式框架及节点/层数，如「6 节点六边形闭环，中心放核心图标」>
【页面文字（逐字照排，不得改写、增删）】
  - 主标题：「…」（特大号加粗）  小节编号：「…」
  - 导语：「…」（关键词「…」「…」用强调色）
  - 模块 1：标题「…」 要点「…」「…」 重点数字「…」（特大号） 标签「…」
  - 模块 2：…
  - 底部横幅：「…」
【图标与装饰】<需要的图标语义，如 增长箭头、齿轮、盾牌；全套同一风格>
【字号层级】重点数字 > 主标题 > 模块标题 > 子标签 > 正文；正文不要小到难读，单卡正文 2–4 行
【约束】不要页码、logo、水印（除非 brief 要求）；中文标点；不要占位符或空白卡片；满而不乱、严格对齐
```

【页面文字】直接取自 outline.md 确认过的文字。大纲里写给自己看的长段说明要先蒸馏成标题、要点和数字，不要整段糊到图上。生僻字或易错词可以在提示词里逐字强调。
